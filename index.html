有机体与环境（Ch 1–3）

第一章：生物与环境（通用规律）

三大定量定律（必考名词）

利比希最小因子定律
植物的生长受处于最低量的必需元素限制。只考虑单因子下限，1840年提出。
限制因子定律（Blackman）
当某生态因子超过耐受上限时，同样限制生物。1905年提出，对最小因子定律的补充。
谢尔福德耐受性定律
任一生态因子在数量或质量上的不足或过多，当超过某种生物的耐受限度时，都会使该生物衰退或不能生存。1913年，包含上下限和质量。
生态幅（Ecological amplitude）
生物对某种生态因子的耐受范围（从最低值到最高值）。在最适值时表现最佳。是上述三定律的核心概念产物。
内稳态（Homeostasis）
生物控制体内环境使其保持相对稳定的机制，能减少对外界条件的依赖，大大提高适应能力。
适应组合（Adaptive suits）
生物对特定环境所表现出的一整套协同适应特性，如骆驼对沙漠缺水的多重适应。

生态因子对生物作用的5大规律

规律核心含义举例
综合作用各生态因子相互影响、相互制约，不孤立存在作物生长受水、光、矿质元素综合作用
主导因子作用诸多因子中有1–2个起主要作用，其改变引起其他因子变化植物春化阶段的低温因子
阶段性作用不同发育阶段需要不同生态因子或其不同强度水是蝌蚪必要条件，成体青蛙依赖性减弱
不可替代性和互补性一因子不可被另一因子完全替代，但可部分补偿CO₂浓度升高可部分补偿光照不足
直接和间接作用生态因子对生物的影响可直接或间接山脉坡向通过改变光照间接影响树木

生物适应的5种形式（必考）

适应方式含义应用
驯化（Acclimation）长期生活于最适范围一侧→耐性限度改变，形成新最适点品种移植、长途运输
休眠（Dormancy）环境超出适宜范围时进入不活动状态，耐受范围拓宽莲的种子、卤虫卵
昼夜和季节节律耐受范围随昼夜/季节呈节律性变化"春捂秋冻"
内稳态控制体内环境稳定，减少对外部条件依赖常温动物体温调节
适应组合对特定环境的一整套协同适应特性骆驼对沙漠的多重适应

第二章（第1节）：生物与光的关系

核心名词

光周期现象（Photoperiodism）
生物借助自然选择和进化形成的对日照长短规律性变化的反应方式。植物开花、动物繁殖/换毛/迁徙均受光周期调控。
昼夜节律（Circadian rhythm）
生物生理活动具有昼夜周期性变化，受外源性周期（光、温、湿等）和内源性生物钟双重控制。
阳生植物 / 阴生植物
阳生植物需强光，补偿点和饱和点高；阴生植物耐弱光，补偿点低，强光下受害。

植物光周期4种类型（必考）

类型条件代表植物
长日照植物日照长于临界日长才能开花小麦、油菜、菠菜
短日照植物日照短于临界日长才能开花水稻、大豆、菊花
中日照植物特定中等日照长度才能开花甘蔗
日中性植物开花对日照长度不敏感番茄、黄瓜

动物的光周期现象

  • 繁殖：长日照动物（春夏繁殖，如仓鼠）/ 短日照动物（秋冬繁殖，如绵羊）
  • 换毛与换羽：随日照变化改变毛色（如白鼬）
  • 昆虫滞育：日照缩短触发滞育，停止发育以度过恶劣季节
  • 候鸟迁徙：光周期是触发候鸟迁徙的重要信号

第二章（第2节）：生物与温度的关系

核心名词

有效积温法则
生物完成某一发育阶段所需总热量（有效积温）是常数K。公式：K = N(T−C)。K：积温常数，N：发育历期（天），T：平均温度，C：生物学零度。
内温动物（Endotherm）
通过自身体内氧化代谢产热来调节体温，即恒温动物（绝大多数鸟类和哺乳类）。
外温动物（Ectotherm）
体温随外界温度改变而改变，即变温动物（鱼类、两栖类、爬行类）。
异温动物（Heterotherm）
体温调节机制介于变温和恒温之间。如冬眠的内温动物，或某些可自主升温的外温动物。
贝格曼规律（Bergmann's Rule）
高纬度地区的恒温动物个体比低纬度同类个体大。体积增大→相对散热面积减小→保温。
阿伦规律（Allen's Rule）
高纬度地区恒温动物身体突出部分（四肢、尾巴、外耳）变短变小，以减少散热。
热中性区（Thermoneutral zone）
动物代谢率最低的环境温度范围，耗氧量不随环境温度改变。

有效积温法则的5大应用

  • 预测某地区害虫发生的世代数
  • 农业规划、引种、作物布局和农时预测
  • 预测生物地理分布北界
  • 预测害虫来年发生程度
  • 计算天敌昆虫合适的释放时间（生物防治）

内温动物对低温的适应（简答题重点）

适应类型具体方式
形态适应贝格曼规律（体型增大）；阿伦规律（附肢缩短）
生理适应① 颤抖性产热与非颤抖性产热；② 逆流热交换机制（动静脉并排，热量回收）；③ 局部异温性（体末端温度低于核心温度）；④ 热中性区；⑤ 适应性低体温（冬眠）
行为适应迁徙、集群（减少散热面积）、穴居

第三章（第1节）：生物与水的关系

鱼类渗透压调节（必考简答/论述）

鱼类渗透压关系排水方式补水方式
淡水硬骨鱼高渗性（血液>水）肾脏发达，排大量低浓度尿鳃主动从稀溶液摄取盐离子
海洋硬骨鱼低渗性（血液<海水）肾小球退化，排极少尿；鳃主动向外排盐大量吞海水
海洋软骨鱼等渗性（靠高浓度尿素+氧化三甲胺维持）直肠腺+肾脏排出多余Na⁺血液高渗透压维持水平衡
广盐性洄游鱼具淡水和海水两种调节特征淡水中排尿量大；海水中鳃排盐海水中大量吞水

植物按水分适应分类

类型分类举例
水生植物沉水 / 浮水 / 挺水轮藻 / 浮萍、睡莲 / 芦苇、水稻
陆生植物湿生 / 中生 / 少浆旱生 / 多浆旱生秋海棠 / 大多数农作物 / 刺叶石竹 / 仙人掌

陆生动物保持水平衡的适应（简答重点）

  • 得水：直接饮水/从食物获得；昆虫从潮湿空气吸水；氧化代谢水；骆驼大量储水
  • 减少蒸发失水：节肢动物角质层+蜡膜；爬行类鳞片；兽类和鸟类皮肤防水
  • 减少呼吸失水：昆虫气孔开闭；荒漠鸟兽利用逆流交换机理（呼出气在气管中冷凝回收水分）
  • 减少排泄失水：尿液浓缩
  • 行为适应：夜间活动、穴居、夏眠

第三章（第2–3节）：大气与土壤

土壤特殊植物（高频考点）

植物类型适应特征
聚盐性植物原生质抗盐性极强，细胞液浓度特别高，根系渗透压高，能吸收高浓度土壤溶液中的水分
泌盐植物将根吸入的多余盐，通过茎叶表面密布的盐腺排出体外
不透盐性植物根细胞对盐类透过性极小，几乎不吸收土壤盐类，但细胞渗透压高，仍能从盐碱土中吸水
沙生植物抗风沙、耐沙埋（被埋后长出不定芽/根）、根上具沙粒囊套保护；具旱生植物特征
旱生植物主根长、侧根宽；叶极端缩小甚至退化；高渗透压；极端干旱时进入休眠

土壤的生态作用

  • 陆地生态系统的基底，具有营养物传递、再循环和废物处理功能
  • 土壤中两个最重要的生态过程：分解过程和固氮过程
  • 为陆生植物提供基质（萌芽、支撑、腐烂、水和矿质营养储存）
  • 为陆生动物提供栖息地

种群生态学（Ch 4–7）

第四章：种群及其基本特征

核心名词

种群（Population）
在同一时期、同一地域内，同种生物个体的集合。是物种在自然界存在的基本单位，也是群落的基本组成单元。
内禀增长率（r）
食物空间不受限、气候适宜、无天敌等理想条件下，种群的最大增长率。
环境容纳量（K值）
在特定环境条件下，某种群能维持的最大个体数量，即逻辑斯谛增长的上限。
综合生命表
在动态生命表基础上，添加了各年龄出生率的生命表，同时包含存活率、死亡率和出生率，是信息最全面的生命表。
动态生命表
总结一组大约同时出生的个体（同生群）从出生到死亡命运的生命表。
静态生命表
对某一特定时间种群年龄结构进行调查编制的生命表，用于难以获得动态生命表数据的情况。
集合种群（Metapopulation）
由空间上相互隔离但有个体迁移联系的若干亚种群组成的种群体系。

种群增长模型对比（必考）

模型公式核心假设曲线形态
J型（指数增长）
与密度无关		连续：Nₜ = N₀eʳᵗ
离散：Nₜ₊₁ = λNₜ		增长率不受密度影响，食物空间无限J型，无上限
S型（逻辑斯谛增长）
与密度有关		dN/dt = rN(1 − N/K)
积分：Nₜ = K/(1 + eᵃ⁻ʳᵗ)		① 存在环境容纳量K；② 增长率随密度按比例降低S型，N=K/2时增速最大（MSY依据）
⭐ S型增长关键点
  • 当N = K/2时，种群增长速率最大，这是最大持续产量（MSY）的理论依据
  • 当N = K时，增长速率 = 0，种群稳定

第五章：生物种及其变异与进化

核心名词

自然选择（Natural selection）
对有差别的存活能力和生殖能力的选择，只在具有不同适合度的、遗传上不同的基因型个体之间发生。
适合度（Fitness）
估计生物所具有各种特征的适应性及其继续往后代传递的能力。W = m（生殖力）× l（存活力）。
遗传漂变（Genetic drift）
基因频率的随机变化，在小种群中随机增减的现象。是偶然性因素，与自然选择（必然性）相对。
遗传瓶颈（Genetic bottleneck）
因环境灾难或过捕等，种群数量急剧下降，基因多样性大量丢失，留存基因库与原种群差异显著。
建立者效应（Founder effect）
少数个体迁移至新地点建立新种群，新种群与母种群基因频率存在较大差异，随时间推移差异越来越大。

物种形成3步骤 × 3方式

⭐ 物种形成3个步骤（必背顺序）
  1. 地理隔离：地理障碍使种群间基因流断绝
  2. 独立进化：各隔离种群在不同选择压力下分别进化
  3. 生殖隔离：形态或遗传差异积累至无法相互交配，新物种形成
方式是否有地理隔离特点
异域性物种形成有（完全隔离）最常见，绝大多数物种形成方式
邻域性物种形成部分隔离在接触边界通过局部适应分化，仍有基因流
同域性物种形成无地理隔离同一地区内，植物多倍体化等方式较常见

特征r-选择者K-选择者

⭐ 生殖价（Vₓ）
  • 某一年龄雌体平均能对未来种群增长所做的贡献

植物CSR三角形对策

对策适应生境特征
C-对策（竞争）低干扰、低胁迫的优良生境高竞争力，快速生长，对应K-选择者

第七章：种内与种间关系

核心名词

最后产量恒值法则
在一定范围内，植物种群的最终产量（生物量）基本恒定，不随播种密度改变——密度高则个体小，密度低则个体大。
-3/2自疏法则
高密度种植中，随密度增大个体不断死亡（自疏），存活个体平均干质量与密度之间呈斜率为-3/2的直线关系。
生态位（Niche）
物种在生物群落中占据的地位和角色，包括维持种群所必需的各种条件、所利用的资源及在环境中出现的时间。
基础生态位 vs 实际生态位
基础生态位：物种能栖息的理论上最大空间；实际生态位：由于竞争等因素，物种实际占据的空间（≤基础生态位）。
竞争排斥原理（高斯法则）
生态位相同的两个物种不可能在同一地区内长期共存，必然出现生态位分化（栖息地、食性、活动时间等分化）。
协同进化（Coevolution）
一个物种的进化对另一物种也产生选择压力，相互推动彼此进化的过程。如捕食者与猎物、植物与传粉者（红皇后效应）。

LV种间竞争模型4种结局（必考）

条件结果
K₁ > K₂/α，且 K₂ < K₁/β物种1取胜，物种2被排除（物种1种间抑制力弱，种内抑制力也弱）
K₂ > K₁/β，且 K₁ < K₂/α物种2取胜，物种1被排除
K₁ > K₂/α，且 K₂ > K₁/β不稳定共存（取决于初始密度，两种均有可能取胜）
K₁ < K₂/α，且 K₂ < K₁/β稳定共存（两者均有各自优势，稳定平衡）

种间关系类型（+/-/0对应）

类型物种1物种2典型例子
竞争−−两种植物争夺光照和矿质元素
捕食+−狼与兔，海星与贻贝
寄生+−寄生虫与宿主
互利共生++根瘤菌与豆科植物，地衣（菌+藻）
偏利共生+0附生植物与大树
偏害共生−0他感作用（植物分泌抑制他种物质）

群落生态学（Ch 8–10）

第八章：群落的组成与结构

群落种类组成（名词解释常考）

优势种 / 建群种
优势种：对群落结构和环境形成有明显控制作用的植物种（个体多、盖度大、生物量高）。
建群种：优势层的优势种，是群落的"创建者"。
亚优势种
作用次于优势种，但在决定群落性质方面仍起一定作用的植物种。
伴生种
群落常见种类，与优势种相伴存在，但不起主要作用。
偶见种/罕见种
出现频率很低、数量十分稀少的种，可能是偶然引入或衰退中的残遗种。
重要值（Importance Value）
综合数量指标。
森林：I.V. = 相对密度 + 相对频度 + 相对优势度（相对基盖度）
草原：I.V. = 相对高度 + 相对频度 + 相对盖度
生活型（Life form）
生物对外界环境适应的外部表现形式（趋同适应）。Raunkiaer按芽的位置分5类：高位芽、地上芽、地面芽、地下芽、一年生植物。
层片（Synusia）
由相同生活型或相似生态要求的种组成的机能群落（H. Gams，1918）。是群落的三维生态结构。
群落交错区 / 边缘效应
群落交错区：两个或多个群落之间的过渡区域（生态过渡带）。
边缘效应：交错区内种的数目及密度增大的趋势。
镶嵌性（Mosaic）
植物在水平方向分布不均匀，形成许多小群落（microcoense）。群落水平结构的主要特征。

生物多样性指数（必考计算题）

指数公式含义
辛普森多样性指数（D）D = 1 − Σ(Nᵢ/N)²随机取样两个个体属于不同种的概率，越大多样性越高
香农-威纳指数（H）H = −Σ Pᵢ log₂ Pᵢ描述种的个体出现的紊乱和不确定性，不确定性越高多样性越高
⭐ α/β/γ多样性
  • α-多样性：在栖息地或群落中的物种多样性（局域尺度）
  • β-多样性：物种组成沿环境梯度从一个群落到另一个群落的变化率
  • γ-多样性：一个地区内穿过一系列群落的总体物种多样性（广域尺度）

中度干扰假说（论述题重点）

⭐ Intermediate Disturbance Hypothesis（Connell提出）
  • 核心：中等程度的干扰能维持物种的最高多样性
  • 低干扰：演替发展到顶级期，竞争排斥导致物种多样性降低
  • 高干扰：先锋种不能发展到演替中期，只有少数耐干扰物种，多样性低
  • 中等干扰：允许更多物种入侵定居，先锋种和中期物种共存，多样性最高
  • 首次提出：在研究潮间带群落时提出（潮间带石头上的物种数随干扰强度呈单峰曲线）

第九章：群落的动态

核心名词

群落演替（Succession）
在同一地点，群落由低级到高级、由简单到复杂的发展变化过程（群落代替现象），一般最终形成顶级群落。
原生演替（Primary succession）
从无植物覆盖的原生裸地（无土壤条件）开始的演替，速度极慢。如冰川退缩地、新火山岩。
次生演替（Secondary succession）
原有植被被破坏后（次生裸地，保留土壤和繁殖体）的演替，速度较快。如森林砍伐、火烧后。
顶级群落（Climax community）
演替的最终稳定阶段，与当地气候相适应的群落。无外来干扰时能长期维持相对稳定。
季相（Aspect）
群落在不同季节的外貌，是群落时间结构（内部动态）的主要特征。

演替过程3种理论模型（必考对比）

模型核心机制关键特点
促进模型（Facilitation）先来物种改变环境，使之有利于后来物种、不利于自身→促进下一阶段物种繁荣类似经典演替观；演替有方向性和可预测性
抑制模型（Inhibition）每个种都试图抑制新来定居者；先到者占优势；r-对策种被K-对策种取代演替具个体性，取决于最初到达的物种；类似个体论
忍耐模型（Tolerance）先锋种不重要，任何种都可开始；替代伴随资源递减，较能忍受有限资源的物种取代其他种演替取决于竞争忍耐能力；资源竞争驱动

演替顶极3大学说（必考对比）

学说核心假设结论
单元顶极学说一个地区只允许有一个气候顶极所有演替都向同一顶极群落发展，由气候决定
多元顶极学说允许有几个顶极群落存在不同土壤、地形可形成不同顶极群落
顶极-格局假说各顶极群落类型连续，沿环境梯度逐渐变化顶极群落形成连续镶嵌格局，难以截然划分

水生演替系列6阶段

阶段主要植物湖底变化
①自由漂浮植物浮萍、满江红等有机质积累，湖底开始抬升
②沉水植物轮藻（5–7m）、高等藻类（2–4m）有机质积累加快
③浮叶根生植物莲、睡莲湖底进一步抬升，水下光照改变
④直立水生芦苇、香蒲根茎茂密，迅速抬高，形成浮岛
⑤湿生草本沼泽植物→旱生草类取代部分抬升出湖面，水分丧失
⑥木本植物灌木→乔木→森林湿生生境→中生生境

生态系统生态学（Ch 11–14）

第十一章：生态系统的一般特征

核心名词

生态系统（Ecosystem）
生物群落与其非生物环境相互作用所形成的功能单元。由非生物环境、生产者、消费者、分解者四个基本成分组成。
食物链（Food chain）
各种生物按取食和被食关系排列的链状顺序。分三类：①捕食食物链；②碎屑食物链；③寄生食物链。
营养级（Trophic level）
处于食物链某一环节上所有生物种的总和。绿色植物为第一营养级，食草动物为第二营养级，以此类推。
生态金字塔（Ecological pyramid）
各营养级之间的数量关系，可用生物量、能量和个体数量表示。
生物放大作用
有毒物质（如DDT）沿食物链向上传递，浓度逐营养级增大的现象。

三种生态金字塔对比（必考）

类型单位是否总是正金字塔关键说明
能量金字塔J/(m²·a)✅ 总是正金字塔能量传递遵循热力学定律（不可逆），逐营养级减少约90%
生物量金字塔g/m²⚠️ 通常是，偶有倒置海洋中浮游植物生物量可能小于浮游动物（周转率不同）
数量金字塔个体数目❌ 可以倒置一棵大树可支持数千只昆虫（数量倒置）
⭐ 为什么能量金字塔总是正三角形？
  • 热力学第二定律：能量传递时不可避免地有一部分以热能形式散失（约90%）
  • 林德曼效率约10%，每升高一个营养级，能量减少约90%
  • 因此能量金字塔必然是从底部到顶部逐渐缩小的正三角形

第十二章：生态系统中的能量流动

能流参数（必考计算）

参数符号含义
摄食量I生物所摄取的能量（植物=光合吸收日光能；动物=吃进食物能量）
同化量A被消化吸收（或固定）的能量。植物中A=GP（总初级生产量）
呼吸量R生物在呼吸等代谢和各种活动中消耗的全部能量
生产量P净剩的同化能量，以有机物质形式积累。P = A − R
总初级生产量GP植物通过光合作用固定的总能量
净初级生产量NPGP − R（植物自身呼吸消耗后的剩余，是消费者可利用的能量）
I = A + FU（粪便）　　A = P + R　　P = A − R
即：摄食量 = 同化量 + 粪便　　同化量 = 生产量 + 呼吸量

四种生态效率（必考）

效率名称公式含义
同化效率（Ae）Ae = Aₙ / Iₙ同化量占摄食量的比例
生产效率（Pe）Pe = Pₙ / Aₙ净生产量占同化量的比例
消费效率（Ce）Ce = Iₙ₊₁ / Pₙ下一营养级消费量占上一营养级净生产量的比例
林德曼效率（Le）Le = Ae × Pe × Ce = Aₙ₊₁ / Aₙ ≈ 10%营养级间同化量之比，即"十分之一定律"

初级生产量的限制因素

生态系统主要限制因素
陆地光、CO₂、水和营养物质（基本资源）；温度（影响光合效率）；食草动物
淡水磷是主要限制因子（N、P、C导致富营养化）
海洋光（1m处吸收50%，20m处仅5–10%）；营养物质（K、P在深水层）

生物地球化学循环3大类型

类型贮存库有无气体分子循环速度代表元素
水循环陆地水体、大气、海洋有（水蒸气）快慢均有H₂O
气体型循环大气和海洋有快C（CO₂）、N（N₂）、O（O₂）、硫（部分）

⭐ 注意：磷仅有沉积型循环，硫兼具两种类型

五大元素循环关键点

元素最大贮存库关键过程重要性
水海洋（约97%）大循环（海陆之间）；小循环（陆地或海洋内部）推动所有物质循环的基础
碳（C）岩石圈（90%以碳酸盐）光合（固定）→呼吸（释放）→大气-海洋CO₂交换→人类化石燃料燃烧生物有机体最重要元素；温室效应核心
氮（N）大气（N₂，约78%）固氮（生物+人工）→氨化→硝化→反硝化蛋白质基本成分；生物不能直接利用N₂
磷（P）陆地土壤（钙盐）岩石风化→植物吸收→消费者→分解→沉积（难返陆地）核酸、细胞膜、ATP、骨骼成分
硫（S）岩石（沉积相硫）风化→盐溶液（陆地水体）；气态（SO₂）→大气→沉降蛋白质和氨基酸基本成分

氮循环4个关键过程（必背）

  1. 固氮作用：将大气中N₂转化为NH₃或其他含氮化合物（生物固氮：根瘤菌、蓝藻；人工固氮：哈伯法）
  2. 氨化作用：微生物将有机氮分解为无机氮（NH₄⁺）
  3. 硝化作用：细菌将NH₄⁺氧化为NO₃⁻（亚硝化菌→硝化菌）
  4. 反硝化作用：细菌将NO₃⁻还原为N₂回到大气，完成循环

第十四章：地球上生态系统的主要类型及其分布

核心名词

地带性植被（显域植被）
分布在显域地境（壤质/黏质土、非盐渍化、排水良好的平地或坡地）上，充分反映当地气候特点的植被。
非地带性植被（隐域植被）
不固定在某一植被带，受特殊生态因素（土壤、地形）控制，呈斑点或条带状嵌入地带性植被中的植被。
纬度地带性
随纬度增高，气候（水热条件）发生递变，植被沿纬度方向更替。
经度地带性
随经度改变，以水分为主导因素，植被沿经度方向更替（沿海→草原→荒漠）。
垂直地带性
随海拔升高，气温、降雨等变化，植被随海拔升高表现出条带状更替，植被带与等高线平行。

主要陆地生态系统（从低纬→高纬）

类型主要分布气候特征代表性特征

亚热带常绿阔叶林亚热带（中国南方）夏热冬温，雨量充沛壳斗科、樟科等常绿阔叶树为主

北方针叶林（泰加林）北纬45°–70°（北美、欧亚）冬季漫长严寒，夏季短暂凉爽松、杉、云杉、冷杉为主；物种多样性低
温带草原大陆内部（内蒙古、北美大平原）半干旱，降雨不足以支持森林禾本科草类为主；无树木或稀少
